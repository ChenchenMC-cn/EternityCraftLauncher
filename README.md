# Eternity Craft Launcher (ECL)

**English** · [简体中文](README.zh-CN.md)

A native, lightweight launcher for Minecraft: Java Edition. C++ does the throughput,
Java does the runtime, C# does the UI and the orchestration.

> **Version 1.0.0** — vanilla, Fabric, Quilt, Forge and OptiFine all install and launch;
> OptiFine can ride on Forge. Per-version mod management, Modrinth search-and-install,
> a self-extracting installer, and a portable mode that keeps settings next to the exe.

---

## Which file do I download?

| File | Size | Who it's for |
|---|---|---|
| **`ECL-Setup.exe`** ← recommended | ≈ 2.6 MB | **Start here.** Double-click to install. If .NET is missing it opens the official download page for you, then launches. |
| `EternityCraftLauncher-single/ECL.exe` | ≈ 59 MB | Portable. Carries its own runtime — copy it to a USB stick and run it anywhere. |
| `EternityCraftLauncher-lite/ECL.exe` | ≈ 1.9 MB | Single file, but **you must install .NET 10 Desktop Runtime** yourself. |

> If you see *"You must install .NET Desktop Runtime"*, you grabbed one of the last two.
> Use `ECL-Setup.exe` instead, or install the runtime from `aka.ms/dotnet/app-launch-failed`.

Requirements: Windows 10 1809 or newer, 64-bit. Java is detected automatically
(and downloaded if missing).

## What it does

- **Vanilla / Fabric / Quilt / Forge / OptiFine** — install and launch, with the loader
  metadata fetched from the official hosts (BMCLAPI mirror optional).
- **Per-version isolation** — each version gets its own `saves/`, `mods/` and
  `options.txt`, so two installs never fight over the same world.
- **Mods** — search Modrinth, install in one click; disable by renaming to
  `.jar.disabled`; removing moves to `mods/.ecl-trash/` instead of deleting.
- **Adopt an existing `.minecraft`** — point it at a folder you already have instead of
  re-downloading 700 MB. Nothing is copied or moved.
- **Pre-launch integrity check** — every start verifies the file list (existence + size)
  and repairs what is missing before the JVM comes up.
- **Crash analysis** — the English stack trace is turned into a plain explanation plus a
  concrete next step (out of memory, mixin conflict, corrupt chunk, bad Java, ...).
- **Diagnostics bundle** — logs, crash reports and settings in one redacted zip.

## Microsoft sign-in needs your own `client_id`

The source ships with **no bundled application id**. Register your own Azure app once
(public client, `http://localhost` redirect, "allow public client flows" = yes, then apply
for the Minecraft API permission at `aka.ms/mce-reviewappid`) and paste the
*Application (client) ID* into **Settings → Microsoft account**.

Why: shipping Microsoft's own launcher id in a public repository means impersonating
their application — see [NOTICE](NOTICE) and the Chinese README for the full story.
Offline accounts, LittleSkin and local skins work with no configuration at all.

## Languages

The launcher ships in **English (US)**; Chinese is one click away in
**Settings → Interface language**. The first-run agreement opens in English (US) too and
can be switched from its own language picker (6 built-in translations, plus optional
`terms/<code>.json` files you can drop into the data folder).

## Building

```bat
AllRebuild.bat              :: full build: native core, Java probe, UI, dist, installer, self-test
AllRebuild.bat --no-bump    :: same, without advancing the version number
scripts\build_all.bat       :: C# only, much faster
scripts\version.bat         :: show / bump the version
```

Toolchain: MSVC (C++20), JDK 8 (`--release 8`, it has to run *on* old JVMs to probe them),
.NET 10 SDK. The scripts locate Visual Studio and the Windows SDK themselves.

`scripts/public-exclude.txt`); it runs a leak check for the official client id, tokens and
private key material before anything is written.

Because of the closed modules, **the published tree does not compile as-is** — you would
need to supply your own sign-in service and native DLL. The interfaces and all call sites
are visible.
